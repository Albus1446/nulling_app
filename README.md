# 看见另一颗地球：消零干涉入门（互动网页讲义）

给大一同学的 Streamlit 单页互动讲义。在正文顶部的「选择章节」单选列表中切换导读和 8 个章节：先看原理示意图，再拖动滑块观察变化，最后用"想一想"检验自己。切换章节后再回来，已调整的参数会在当前浏览器会话中保留。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器会自动打开 http://localhost:8501，在同一个页面中选择章节。原来的 `streamlit run 首页.py` 命令也可继续使用，展示的是同一套单页界面。

## 章节

| 节 | 主题 | 互动内容 |
|---|---|---|
| 0 | 导读：灯塔旁的萤火虫 | 调望远镜口径，看行星是否被恒星光斑淹没 |
| 1 | 光的干涉 | 调相位差、光程差，看两列波相长或相消 |
| 2 | 两台望远镜消零 | 光路原理图；调基线、波长、行星位置，看天空上的"百叶窗" |
| 3 | 恒星的漏光 | 调距离、基线、波长，看恒星圆盘漏多少光，漏光与行星比谁亮 |
| 4 | 四台望远镜与斩波 | 阵列与合束框图；三张透射图；对称尘埃环在斩波后消失 |
| 5 | 旋转阵列 | 拖动旋转角，同步看阵列、行星轨迹与信号；比较两个位置的"指纹" |
| 6 | 光子噪声与信噪比 | √N 起伏；暗输出里光子的来源；观测时间与 SNR |
| 7 | 找到行星 | 相关图（"听歌识曲"）；再观测一次；100 次模拟统计找对的比例 |
| 8 | 参数实验室 | 选恒星类型、距离、尘埃量、基线，看 SNR 与所需观测时间；挑战任务 |

## 文件

- `app.py`：统一入口、章节单选导航、9 个章节渲染函数；每次只运行当前选中的章节
- `首页.py`：原启动命令的兼容入口
- `schematics.py`：所有原理示意图的画法
- `core.py`：物理计算（透射、光源模型、光子计数、相关图）
- `app_common.py`：公共显示工具、章节参数保存与恢复、计算缓存
- `.streamlit/config.toml`：蓝色主题配置

导航和教学节奏参考 [jkanner/streamlit-audio 的 app.py](https://github.com/jkanner/streamlit-audio/blob/main/app.py)：使用 `st.radio` 选择章节，先提出问题，再邀请读者改变一个参数、比较图形，最后解释观察结果。讲解用中文重新编写；物理计算与绘图仍各自放在模块中。

## 部署与中文显示

项目固定使用已验证的 `streamlit==1.65.0`，避免每次重新部署自动升级前端运行时。更新依赖后，让 Streamlit Community Cloud 完成重新构建，再刷新浏览器中的旧标签页。`Importing a module script failed` 是浏览器加载前端模块失败；如果仍出现，需核对失败的静态资源地址和 HTTP 状态。固定版本不会修复托管平台本身的静态资源故障。

`assets/fonts/` 随项目附带 Noto Sans SC 中文字体及 SIL Open Font License。绘图时直接注册这个本地文件，Linux 云端不需要预装中文字体，也不会在打开页面时从外部字体网站下载。图标题按实际字宽换行，图片以留有边距的 PNG 展示，避免中文变方框或被裁切。

模型假定仪器是理想的，唯一的噪声是光子噪声。参数实验室首次切换到新的组合时需要计算约 1–2 秒，之后会缓存。

## 检查

```bash
python -m unittest discover -s tests -v
```

检查全部章节渲染、同名参数在各章节之间的独立性、切换后的参数恢复、随机观测与 100 次模拟，以及原启动命令的兼容性。
