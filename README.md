# 从光的干涉到四集光器消零

中文 Streamlit 单页互动讲义。中文使用 Noto Serif CJK SC，数字、拉丁字母与常规符号优先使用 Cormorant Garamond。先学习三个概念，再用目标参数驱动天空贡献、光子预算与行星定位，最后练习匹配滤波。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

原命令 `streamlit run 首页.py` 也会打开同一界面。正文中的章节单选列表负责切换，各节参数在当前浏览器会话中保留。

## 模型与归一化

- 集光器顺序：(L,qL)、(L,−qL)、(−L,−qL)、(−L,qL)，L=b/2。合光矩阵的后两行与只读参考 `code_main/nulling_main_indep/nulling_main_indep.py` 的 `get_perturbed_transmission`、`other_code/nulling_ext/transmission.py` 一致。
- 对同一方向先相加复振幅，T_k=|(Uv)_k|²/4。U 为酉矩阵，无衍射时四路功率之和为入射总功率。
- 教学模型采用理想、相同圆孔的夫琅禾费振幅，A=[2J1(u)/u]²，R_k=A·T_k。实际单模耦合需额外的模场重叠积分。
- 不同天空位置的热辐射按非相干强度积分。恒星/行星采用黑体；本地黄道光和正面朝向的轴对称外黄道尘模型沿用参考程序的思路。恒星盘使用独立细网格计算漏光，避免粗显示网格把恒星误当成完美点源。
- 对比度定义为行星/恒星通量。双光束概念实验的消零深度为暗/亮强度比；后续场景的几何漏光明确以入射恒星总通量为分母。
- 第 2 节展示的是透射加权天空贡献图，**不是探测器的直接像或重建像**。图中未分辨的恒星/行星以像素示意；总输出使用细恒星盘积分和精确行星坐标。色标相对固定参考类地行星，便于比较通量变化。条纹采样随基线和波长加密，避免数值混叠。
- 改目标参数会改天空亮度与输出贡献；固定仪器时，透射条纹保持不变。对称尘埃在差分的全视场积分中抵消平均值，但每个像素的贡献与光子噪声仍在。

第二节的光谱预算逐谱道积分，采用与天空贡献图相同的 ±400 mas 圆形接收场、圆孔衍射与合光矩阵，计数乘四孔总面积和后端效率。天空图所选波长与角度不改变后续整圈、多波长预算。超出接收场的行星不进行定位。

匹配得分为 Q=Σ(dt/σ²)/√Σ(t²/σ²)，幅度采用非负加权最小二乘；每个候选模板独立归一化。第二节把行星谱形、衍射和每步积分计入模板，使用 >6 µm 谱道、每 8° 采样与 61×61 网格定位；预期 SNR 则使用所有谱道和每 1° 采样。SNR=5 是教学参考，未校准多位置搜索的虚警率。第三节为固定方位角的单波长距离匹配，独立噪声采用高计数时的高斯近似；距离滑动不改变当前模拟数据。

`code_main` 只作为只读参考，没有从该目录运行脚本，也没有修改其中的文件。

## 字体与部署

页面和图件使用混合字体：非中文文字优先采用 [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)，中文回退到 [Noto Serif CJK SC](https://github.com/notofonts/noto-cjk/tree/main/Serif/OTF/SimplifiedChinese)。页面使用本地 WOFF2，图件使用项目内的静态 TTF/OTF；授权见 `assets/fonts/`。缺失符号保留兼容字体回退，网页公式继续使用 KaTeX 的数学字形与排版。所有字体通过项目分发，无外部字体服务。

运行时固定为已验证的 `streamlit==1.65.0`。依赖更新后等待 Community Cloud 重新构建，再刷新旧标签页。若浏览器仍显示模块导入失败，应核对失败静态资源的 HTTP 状态；版本固定不会修复托管平台自身的资源故障。
