# 看见另一颗地球：消零干涉入门（互动网页讲义）

给大一同学的 Streamlit 互动讲义。每页一个概念：先看原理示意图，再拖动滑块观察变化，最后用"想一想"检验自己。

## 运行

```bash
pip install -r requirements.txt
streamlit run 首页.py
```

浏览器会自动打开 http://localhost:8501，左侧菜单可以逐页切换。

## 页面

| 页 | 主题 | 互动内容 |
|---|---|---|
| 首页 | 为什么难：灯塔旁的萤火虫 | 调望远镜口径，看行星是否被恒星光斑淹没 |
| 1 | 光的干涉 | 调相位差、光程差，看两列波相长或相消 |
| 2 | 两台望远镜消零 | 光路原理图；调基线、波长、行星位置，看天空上的"百叶窗" |
| 3 | 恒星的漏光 | 调距离、基线、波长，看恒星圆盘漏多少光，漏光与行星比谁亮 |
| 4 | 四台望远镜与斩波 | 阵列与合束框图；三张透射图；对称尘埃环在斩波后消失 |
| 5 | 旋转阵列 | 拖动旋转角，同步看阵列、行星轨迹与信号；比较两个位置的"指纹" |
| 6 | 光子噪声与信噪比 | √N 起伏；暗输出里光子的来源；观测时间与 SNR |
| 7 | 找到行星 | 相关图（"听歌识曲"）；再观测一次；100 次模拟统计找对的比例 |
| 8 | 参数实验室 | 选恒星类型、距离、尘埃量、基线，看 SNR 与所需观测时间；挑战任务 |

## 文件

- `首页.py`、`pages/`：各页面
- `schematics.py`：所有原理示意图的画法
- `core.py`：物理计算（透射、光源模型、光子计数、相关图）
- `app_common.py`：页面公共工具与计算缓存

模型假定仪器是理想的，唯一的噪声是光子噪声。参数实验室首次切换到新的组合时需要计算约 1–2 秒，之后会缓存。
