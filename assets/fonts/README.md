# Noto Serif CJK SC

- 原始字体：`NotoSerifCJKsc-Regular.otf`，用于 Matplotlib 图件。
- 来源：[Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk/tree/main/Serif/OTF/SimplifiedChinese)。
- 授权：SIL Open Font License 1.1，见 `OFL-Serif.txt`。
- 页面使用 `static/fonts/noto-serif-cjk-sc.woff2`，由同一字体按讲义所需字形生成的网页子集。
- 字体均随项目分发，不依赖外部字体网站。

# Cormorant Garamond

- 来源：[Google Fonts 官方仓库](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)。
- 图件使用从官方可变字体导出的 Regular 400、Bold 700、Italic 400 静态实例。
- 页面使用同源可变字体转换的 WOFF2，覆盖 300–700 字重。
- 授权见 `OFL-Cormorant.txt`。
- 字体列表将 Cormorant Garamond 放在前面，让数字与拉丁字母优先使用它；中文回退到 Noto Serif CJK SC。
